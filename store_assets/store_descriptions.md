# DupeSweep — Chrome Web Store Descriptions

## English — en (default)

**Description:**

Too many tabs open? Chances are, some of them are duplicates. DupeSweep detects tabs with identical URLs and sweeps away the extras — keeping your browser fast, clean, and organized.

It's smart about it: your active tab and pinned tabs are always preserved. If you're on a duplicate tab, DupeSweep closes the others so you can keep working without interruption. It even recognizes suspended tabs from extensions like Marvellous Suspender.

🎯 KEY FEATURES:
• Instantly detect and sweep duplicate tabs across all windows
• Smart preservation of active and pinned tabs
• Real-time badge showing your duplicate count
• Works with tab suspender extensions
• Keyboard shortcut: Alt+Shift+D (Option+Shift+D on Mac)

⚙️ SETTINGS & CUSTOMIZATION:
• Auto-Sweep: Automatically remove duplicates as they appear
• Current Window Only: Limit detection to your active window
• Sort Tabs: Organize all tabs alphabetically by URL
• Per-domain statistics with interactive search

🔒 PRIVACY FIRST:
• Zero data collection — nothing leaves your browser
• All processing happens locally
• Open source — full code transparency
• Minimal permissions (tabs + storage only)

🎨 CLEAN INTERFACE:
• Modern popup with duplicate list and domain overview
• Click any duplicate to jump to that tab
• Two-panel settings with collapsible sections
• Supports 8 languages: English, Bulgarian, Chinese, French, Hindi, Italian, Russian, Spanish

Perfect for developers, researchers, power users, and anyone drowning in tabs. Install DupeSweep and take back control of your browser.
